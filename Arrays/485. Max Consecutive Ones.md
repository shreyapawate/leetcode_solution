# 485. Max Consecutive Ones

## Pattern
Array Traversal (Counting)

## Recognition
- Traverse the array once.
- Find the maximum length of consecutive occurrences.
- Reset count when a different value is encountered.
- O(n) solution expected.

## Core Idea
Maintain two variables:

- `count` → Current consecutive `1`s.
- `maxCount` → Maximum consecutive `1`s seen so far.

While traversing:
- If current element is `1`, increment `count`.
- Otherwise, update `maxCount` and reset `count` to `0`.

Finally, update `maxCount` one last time because the array may end with `1`s.

## Algorithm
1. Initialize:
   - `count = 0`
   - `maxCount = 0`
2. Traverse the array:
   - If `nums[i] == 1`:
     - `count++`
   - Else:
     - Update `maxCount`
     - Reset `count`
3. Update `maxCount` after the loop.
4. Return `maxCount`.

## Pseudocode

```java
count = 0
maxCount = 0

for(num : nums):

    if(num == 1):

        count++

    else:

        maxCount = max(maxCount, count)

        count = 0

maxCount = max(maxCount, count)

return maxCount
```

## Key Syntax

```java
int count = 0;
int maxCount = 0;

if(nums[i] == 1)
    count++;
else{
    maxCount = Math.max(maxCount, count);
    count = 0;
}

maxCount = Math.max(maxCount, count);

return maxCount;
```

## Complexity

Time: O(n)

Space: O(1)

## Template Insight

Whenever:
- Find the longest consecutive sequence.
- Count contiguous occurrences.
- Reset when the condition breaks.

Think:

**Count → Update Maximum → Reset**

## Common Mistake

❌ Counting `0`s instead of `1`s.

Wrong:

```java
if(nums[i] == 0)
    count++;
```

Correct:

```java
if(nums[i] == 1)
    count++;
```

Also, don't forget the final update after the loop:

```java
maxCount = Math.max(maxCount, count);
```

Otherwise, you'll miss cases where the array ends with consecutive `1`s.
