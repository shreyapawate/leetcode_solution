# 83. Remove Duplicates from Sorted List

## Pattern
Linked List Traversal

## Recognition
- Linked list is **sorted**.
- Remove duplicate nodes.
- Keep **one occurrence** of each value.
- Modify the list in-place.

## Core Idea
Since the list is sorted, duplicate nodes are always **adjacent**.

Traverse the list:
- If the current node and next node have the same value, skip the next node.
- Otherwise, move to the next node.

## Algorithm
1. Initialize `current = head`.
2. While `current != null` and `current.next != null`:
   - If values are equal:
     - Remove the next node.
   - Else:
     - Move to the next node.
3. Return `head`.

## Pseudocode

```java
current = head

while(current != null &&
      current.next != null):

    if(current.val == current.next.val):

        current.next = current.next.next

    else:

        current = current.next

return head
```

## Key Syntax

```java
ListNode current = head;

while(current != null &&
      current.next != null){

    if(current.val == current.next.val){

        current.next = current.next.next;

    }else{

        current = current.next;
    }
}

return head;
```

## Complexity

Time: O(n)

Space: O(1)

## Template Insight

Whenever:
- Sorted linked list.
- Need to remove duplicates.
- Keep exactly one occurrence.

Think:

**Compare Adjacent Nodes → Skip Duplicate → Otherwise Move Forward**

## Why Don't We Move `current` After Deletion?

Example:

```text
1 → 1 → 1 → 2
```

If you delete one duplicate and immediately move `current`:

```text
1 → 1 → 2
     ↑
```

you skip checking the remaining duplicate.

Correct approach:

```java
current.next = current.next.next;
```

Do **not** move `current` after deletion.

Only move when the values are different.

## Common Mistakes

❌ Moving `current` after removing a duplicate.

Wrong:

```java
current.next = current.next.next;
current = current.next;
```

Correct:

```java
current.next = current.next.next;
```

---

❌ Forgetting to check `current.next != null`.

Always use:

```java
while(current != null &&
      current.next != null)
```

- Sorted list → duplicates are adjacent.
- Compare `current` with `current.next`.
- Equal → bypass next node.
- Different → move forward.
- Don't move after deletion.
