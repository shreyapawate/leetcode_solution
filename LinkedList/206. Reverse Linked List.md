# 206. Reverse Linked List

## Pattern
Linked List (Pointer Manipulation)

## Recognition
- Reverse a singly linked list.
- Modify links in-place.
- O(n) time and O(1) space expected.

## Core Idea
Maintain three pointers:

- `prev` → Previous node.
- `curr` → Current node.
- `next` → Stores the next node before changing the link.

For every node:
1. Save the next node.
2. Reverse the current node's pointer.
3. Move all pointers one step ahead.

## Algorithm
1. Initialize:
   - `prev = null`
   - `curr = head`
2. While `curr != null`:
   - Save `curr.next`.
   - Reverse the link.
   - Move `prev` and `curr`.
3. Return `prev` as the new head.

## Pseudocode

```java
prev = null
curr = head

while(curr != null):

    next = curr.next

    curr.next = prev

    prev = curr

    curr = next

return prev
```

## Key Syntax

```java
ListNode prev = null;
ListNode curr = head;
ListNode next;

while(curr != null){

    next = curr.next;

    curr.next = prev;

    prev = curr;

    curr = next;
}

return prev;
```

## Complexity

Time: O(n)

Space: O(1)

## Template Insight

Whenever:
- Reverse a linked list.
- Reverse a part of a linked list.
- Reverse nodes in groups.

Think:

**Save → Reverse → Move**

## Pointer Visualization

Before:

```text
prev      curr
 |          |
null <- 1 -> 2 -> 3 -> null
```

After one iteration:

```text
      prev      curr
       |          |
null <- 1     2 -> 3 -> null
```

After completion:

```text
null <- 1 <- 2 <- 3

Return:

3 -> 2 -> 1
```

## Common Mistakes

❌ Forgetting to save the next node.

Wrong:

```java
curr.next = prev;
curr = curr.next;
```

You lose the rest of the list.

Correct:

```java
next = curr.next;
curr.next = prev;
curr = next;
```

---

❌ Returning `head`.

After reversal, the new head is:

```java
return prev;
```
