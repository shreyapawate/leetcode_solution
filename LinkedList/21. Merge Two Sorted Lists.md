# 21. Merge Two Sorted Lists

## Pattern
Linked List (Two Pointers)

## Recognition
- Two sorted linked lists.
- Merge into one sorted linked list.
- Reuse existing nodes (no new nodes except an optional dummy).

## Core Idea
Maintain two pointers:
- `list1`
- `list2`

Compare their values:
- Append the smaller node to the merged list.
- Move the corresponding pointer.
- Continue until one list becomes empty.
- Attach the remaining nodes.

## Algorithm
1. Initialize a dummy node and a `tail` pointer.
2. While both lists are non-empty:
   - Compare `list1.val` and `list2.val`.
   - Attach the smaller node to `tail`.
   - Move the corresponding list pointer.
   - Move `tail`.
3. Attach the remaining list.
4. Return `dummy.next`.

## Pseudocode

```java
dummy = new ListNode()
tail = dummy

while(list1 != null &&
      list2 != null):

    if(list1.val <= list2.val):

        tail.next = list1
        list1 = list1.next

    else:

        tail.next = list2
        list2 = list2.next

    tail = tail.next

if(list1 != null)
    tail.next = list1

if(list2 != null)
    tail.next = list2

return dummy.next
```

## Key Syntax

```java
ListNode dummy = new ListNode();

ListNode tail = dummy;

tail.next = list1;
list1 = list1.next;

tail.next = list2;
list2 = list2.next;

tail = tail.next;

return dummy.next;
```

## Complexity

Time: O(n + m)

- `n` = length of list1
- `m` = length of list2

Space: O(1)

## Template Insight

Whenever:
- Two sorted linked lists.
- Need to merge while maintaining sorted order.

Think:

**Compare → Attach Smaller → Move Pointer**

## Common Mistakes

❌ Forgetting to attach the remaining nodes.

Wrong:

```java
while(list1 != null &&
      list2 != null){
    ...
}
```

Then directly returning the list.

Correct:

```java
if(list1 != null)
    tail.next = list1;

if(list2 != null)
    tail.next = list2;
```

---

❌ Returning `dummy` instead of `dummy.next`.

The merged list starts from:

```java
return dummy.next;
```

- Use two pointers.
- Compare current nodes.

- Move `tail`.
- Attach the remaining list.
