# 2596. Check Knight Tour Configuration

## Pattern
Recursion / DFS (Knight Move Validation)

## Recognition
- Grid contains numbers from `0` to `n² - 1`.
- Need to verify a valid knight's tour.
- Each next value must be reached by a legal knight move.

## Core Idea
Start from the cell containing `0`.

For each expected value:
- Find the next value (`current + 1`) using one of the **8 knight moves**.
- If found, continue recursively (or iteratively).
- If not, return `false`.

The tour is valid only if all values from `0` to `n² - 1` are visited in order.

## Knight Moves

```text
(-2, +1)
(-2, -1)

(-1, +2)
(-1, -2)

(+1, +2)
(+1, -2)

(+2, +1)
(+2, -1)
```

## Algorithm
1. Check that `grid[0][0] == 0`.
2. Start from `(0, 0)` with expected value `0`.
3. If expected value is `n² - 1`, return `true`.
4. Try all 8 knight moves.
5. Move only if the next cell contains `expected + 1`.
6. If none works, return `false`.

## Pseudocode

```java
isValid(row, col, expected):

    if(expected == n*n - 1)
        return true

    for(each knight move):

        newRow = row + dr[i]
        newCol = col + dc[i]

        if(valid cell &&
           grid[newRow][newCol] == expected + 1)

            return isValid(newRow,
                           newCol,
                           expected + 1)

    return false
```

## Key Syntax

```java
int[] dr = {-2,-2,-1,-1,1,1,2,2};

int[] dc = {-1,1,-2,2,-2,2,-1,1};

if(r >= 0 &&
   c >= 0 &&
   r < n &&
   c < n)

grid[r][c] == expected + 1;
```

## Complexity

Time: O(n²)

- Every value from `0` to `n² - 1` is visited once.

Space:
- Recursive: O(n²) (call stack)
- Iterative: O(1)

- Follow values in increasing order.
- Use 8 knight moves.
- If every move is valid → true.
