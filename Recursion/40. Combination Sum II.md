# 40. Combination Sum II

## Pattern
Backtracking + Sorting + Duplicate Skipping

## Recognition
- Generate **unique** combinations.
- Each element can be used **at most once**.
- Input may contain duplicate values.
- Order within a combination does not matter.

## Core Idea
1. **Sort** the array so duplicates are adjacent.
2. At each recursive call, iterate through the remaining elements.
3. Skip duplicate values at the **same recursion level**.
4. Since each element can be used only once, recurse with `i + 1`.

## Algorithm
1. Sort `candidates`.
2. Start recursion from index `0`.
3. If `target == 0`:
   - Store a copy of the current combination.
4. Iterate from `start` to `n - 1`:
   - Skip duplicates:
     ```java
     if(i > start && candidates[i] == candidates[i - 1])
         continue;
     ```
   - If `candidates[i] > target`, break (array is sorted).
   - Choose the element.
   - Recurse with `i + 1`.
   - Backtrack.

## Pseudocode

```java
sort(candidates)

backtrack(start, target):

    if(target == 0):

        ans.add(copy of current)

        return

    for(i = start; i < n; i++):

        if(i > start &&
           candidates[i] == candidates[i - 1])
            continue

        if(candidates[i] > target)
            break

        current.add(candidates[i])

        backtrack(i + 1,
                  target - candidates[i])

        current.remove(last element)
```

## Key Syntax

```java
Arrays.sort(candidates);

if(i > start &&
   candidates[i] == candidates[i - 1])
    continue;

if(candidates[i] > target)
    break;

current.add(candidates[i]);

current.remove(current.size() - 1);

ans.add(new ArrayList<>(current));

backtrack(i + 1, target - candidates[i]);
```

## Complexity

Let:
- `N` = number of elements

Time: O(2^N) (worst case)

Space: O(N) recursion depth (excluding output)

Sorting: O(N log N)

## Template Insight

Whenever:
- Unique combinations.
- Duplicates present.
- Each element used **once**.

Think:

**Sort → Skip Duplicates → Backtrack**

## Why Skip Duplicates?

Example:

```text
Candidates = [1,1,2]
```

Without skipping:

```text
First 1 → [1,2]

Second 1 → [1,2]   ❌ Duplicate
```

Using:

```java
if(i > start &&
   candidates[i] == candidates[i - 1])
    continue;
```

only the **first occurrence at the current recursion level** is considered.
