# 78. Subsets

## Pattern
Backtracking (Take / Skip)

## Recognition
- Generate **all possible subsets**.
- Every element can either be included or excluded.
- No duplicate elements in the input.
- Order of subsets does not matter.

## Core Idea
For every element, there are exactly **two choices**:

1. **Take** the element.
2. **Don't take** the element.

When all elements have been considered (`idx == n`), store the current subset.

## Algorithm
1. Start from index `0`.
2. If `idx == n`:
   - Store a copy of the current subset.
   - Return.
3. Take the current element.
4. Recurse for the next index.
5. Backtrack.
6. Skip the current element.
7. Recurse for the next index.

## Pseudocode

```java
backtrack(idx):

    if(idx == n):

        ans.add(copy of current)

        return

    // Take
    current.add(nums[idx])

    backtrack(idx + 1)

    current.remove(last element)

    // Skip
    backtrack(idx + 1)
```

## Key Syntax

```java
List<List<Integer>> ans = new ArrayList<>();

List<Integer> current = new ArrayList<>();

current.add(nums[idx]);

current.remove(current.size() - 1);

ans.add(new ArrayList<>(current));

backtrack(idx + 1);
```

## Complexity

Time: O(n × 2ⁿ)

- There are `2ⁿ` subsets.
- Copying each subset takes up to `O(n)`.

Space: O(n) recursion depth (excluding output)

## Template Insight

Whenever:
- Generate all subsets.
- Every element has two independent choices.
- No duplicates.

Think:

```text
Take
  |
Backtrack
  |
Don't Take
```

## Recursion Tree

Example:

```text
nums = [1,2]
```

```text
                    []
                 /      \
              Take 1   Skip 1
             /              \
         [1]                 []
        /   \               /   \
    [1,2] [1]           [2]     []
```

Output:

```text
[1,2]
[1]
[2]
[]
```

## Revision (15 sec)

- Two choices per element.
- Take → recurse.
- Undo.
- Skip → recurse.
- Save subset when `idx == n`.
- Time: O(n × 2ⁿ).
