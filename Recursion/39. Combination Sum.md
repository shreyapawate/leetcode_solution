# 39. Combination Sum

## Pattern
Backtracking (Choose / Skip)

## Recognition
- Generate **all** valid combinations.
- Need combinations, not just one answer.
- An element can be chosen **unlimited times**.
- Sum must equal the target.

## Core Idea
At every index, there are only **two choices**:

1. **Take** the current element.
   - Add it to the current combination.
   - Stay at the **same index** (reuse allowed).

2. **Skip** the current element.
   - Move to the **next index**.

Whenever `target == 0`, store the current combination.

## Algorithm
1. Start from index `0`.
2. If `target == 0`:
   - Add a copy of the current combination.
3. If `idx == n` or `target < 0`:
   - Return.
4. Choose the current element:
   - Add it.
   - Recurse with the same index.
   - Remove it (backtrack).
5. Skip the current element:
   - Recurse with `idx + 1`.

## Pseudocode

```java
backtrack(idx, target):

    if(target == 0):
        ans.add(copy of current)
        return

    if(idx == n || target < 0):
        return

    // Take
    current.add(nums[idx])

    backtrack(idx, target - nums[idx])

    current.remove(last element)

    // Skip
    backtrack(idx + 1, target)
```

## Key Syntax

```java
List<List<Integer>> ans = new ArrayList<>();

List<Integer> current = new ArrayList<>();

current.add(nums[idx]);

current.remove(current.size() - 1);

ans.add(new ArrayList<>(current));

backtrack(idx, target - nums[idx]);

backtrack(idx + 1, target);
```

## Complexity

Let:
- `N` = number of candidates
- `T` = target
- `M` = average length of a valid combination

Time: Exponential (depends on the number of valid combinations)

Space: O(T) recursion depth (excluding output)

## Template Insight

Whenever:
- Need **all combinations**.
- Reuse of elements is allowed.
- Decision at each step is **Take or Skip**.

Think:

```text
Choose
↓
Explore
↓
Undo (Backtrack)
```

## Common Backtracking Template

```java
Choose

Recurse

Undo

Recurse
```

## Revision (15 sec)

- Two choices: Take / Skip.
- Take → stay at same index.
- Skip → move to next index.
- `target == 0` → save copy.
- Always backtrack using `remove(last)`.
