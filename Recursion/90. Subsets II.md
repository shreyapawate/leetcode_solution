# 90. Subsets II

## Pattern
Backtracking + Sorting + Duplicate Skipping

## Recognition
- Generate **all unique subsets**.
- Input may contain duplicate elements.
- Order of subsets does not matter.

## Core Idea
1. **Sort** the array so duplicates are adjacent.
2. At every recursive call:
   - Store the current subset.
   - Iterate from `start` to `n - 1`.
3. Skip duplicate elements at the **same recursion level**.
4. Choose an element, recurse, then backtrack.

> Unlike **Subsets (78)**, the answer is added at **every recursive call**, because every current subset is valid.

## Algorithm
1. Sort the array.
2. Start recursion from index `0`.
3. Add the current subset to the answer.
4. Iterate from `start` to `n - 1`:
   - Skip duplicates:
     ```java
     if(i > start && nums[i] == nums[i - 1])
         continue;
     ```
   - Choose the current element.
   - Recurse with `i + 1`.
   - Backtrack.

## Pseudocode

```java
sort(nums)

backtrack(start):

    ans.add(copy of current)

    for(i = start; i < n; i++):

        if(i > start &&
           nums[i] == nums[i - 1])
            continue

        current.add(nums[i])

        backtrack(i + 1)

        current.remove(last element)
```

## Key Syntax

```java
Arrays.sort(nums);

ans.add(new ArrayList<>(current));

if(i > start &&
   nums[i] == nums[i - 1])
    continue;

current.add(nums[i]);

current.remove(current.size() - 1);

backtrack(i + 1);
```

## Complexity

Time: O(n × 2ⁿ)

- Up to `2ⁿ` subsets.
- Copying each subset takes `O(n)`.

Space: O(n) recursion depth (excluding output)

## Template Insight

Whenever:
- Need all unique subsets.
- Input contains duplicates.

Think:

**Sort → Add Current Subset → Skip Duplicates → Backtrack**

## Why Skip Duplicates?

Example:

```text
nums = [1,2,2]
```

Without skipping:

```text
[]
[1]
[1,2]
[1,2]   ❌ Duplicate
```

Using:

```java
if(i > start &&
   nums[i] == nums[i - 1])
    continue;
```

ensures that only the **first occurrence** of a duplicate is considered at the same recursion level.
