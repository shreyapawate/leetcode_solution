# 1903. Largest Odd Number in String

## Pattern
Greedy + String Traversal

## Recognition
- Given a numeric string.
- Find the largest-valued odd substring.
- Need to preserve the original order of digits.
- O(n) solution expected.

## Core Idea
A number is **odd** if its **last digit is odd**.

To obtain the **largest odd substring**, find the **rightmost odd digit**.
The answer is simply the prefix ending at that digit.

Why?
- Removing digits from the front changes the number and makes it smaller.
- Removing digits from the end until the last digit is odd gives the largest possible odd substring.

## Algorithm
1. Traverse the string from right to left.
2. Find the first odd digit.
3. Return the substring from index `0` to that index.
4. If no odd digit exists, return an empty string.

## Pseudocode

```java
for(i = n - 1; i >= 0; i--):

    digit = s.charAt(i) - '0'

    if(digit % 2 == 1):

        return s.substring(0, i + 1)

return ""
```

## Key Syntax

```java
for(int i = s.length() - 1; i >= 0; i--)

int digit = s.charAt(i) - '0';

if(digit % 2 == 1)

return s.substring(0, i + 1);

return "";
```

## Complexity

Time: O(n)

Space: O(1)

## Template Insight

Whenever:
- Need the largest valid prefix/suffix.
- Condition depends only on the last character.
- String should not be rearranged.

Think:

**Traverse from the End → Return Prefix**

## Why Does This Work?

Example:

```text
s = "35427"
```

Rightmost odd digit:

```text
7
```

Answer:

```text
35427
```

Example:

```text
s = "35420"
```

Rightmost odd digit:

```text
5
```

Answer:

```text
3542❌
354 ✔
```

Actually:

```text
Substring = "3542"? ❌ (ends with 2, even)

Substring = "354" ✔
```

Since the rightmost odd digit is at index `2`, return:

```java
s.substring(0, 3)   // "354"
```
