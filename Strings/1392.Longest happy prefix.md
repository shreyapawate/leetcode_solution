# 1392. Longest Happy Prefix

## Pattern
KMP (Longest Prefix Suffix - LPS Array)

## Recognition
- Need the longest prefix that is also a suffix.
- Prefix and suffix should **not** overlap completely.
- Efficient string matching/prefix computation.

## Core Idea
Build the **LPS (Longest Prefix Suffix)** array.

- `lps[i]` stores the length of the longest proper prefix which is also a suffix for `s[0...i]`.
- The last value of the LPS array gives the length of the longest happy prefix.
- Return the substring from `0` to `lps[n-1]`.

## Algorithm
1. Create an LPS array of size `n`.
2. Initialize:
   - `pre = 0`
   - `suf = 1`
3. While `suf < n`:
   - If characters match:
     - Increase prefix length.
     - Store in LPS.
   - Else:
     - If `pre == 0`, set LPS to `0`.
     - Otherwise, move `pre` to `lps[pre-1]`.
4. Return `s.substring(0, lps[n-1])`.

## Pseudocode

```java
lps = new int[n]

pre = 0
suf = 1

while(suf < n):

    if(s.charAt(pre) == s.charAt(suf)):

        pre++
        lps[suf] = pre
        suf++

    else:

        if(pre == 0):

            lps[suf] = 0
            suf++

        else:

            pre = lps[pre - 1]

return s.substring(0, lps[n - 1])
```

## Key Syntax

```java
int[] lps = new int[s.length()];

s.charAt(i);

lps[suf] = pre + 1;

s.substring(0, lps[s.length() - 1]);
```

Time: O(n)

Space: O(n)
