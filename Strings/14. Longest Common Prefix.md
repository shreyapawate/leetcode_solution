# 14. Longest Common Prefix

## Pattern
Horizontal Scanning (String Comparison)

## Recognition
- Find the common prefix among multiple strings.
- Compare characters column by column.
- Stop at the first mismatch.

## Core Idea
The common prefix cannot be longer than the shortest string.

Compare the characters at the same index across all strings:
- If all match, include the character.
- If any mismatch occurs, stop and return the prefix found so far.

## Algorithm
1. Find the length of the shortest string.
2. For each index `i` from `0` to `minLength - 1`:
   - Take the character from the first string.
   - Compare it with the character at index `i` in every other string.
   - If any mismatch occurs, return the prefix.
3. Return the complete prefix.

```java

```

## Complexity

Time: O(n × m)

- `n` = number of strings
- `m` = length of the shortest string

Space: O(1) extra (excluding output)
