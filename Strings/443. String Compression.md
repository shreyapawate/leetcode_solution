# 443. String Compression

## Pattern
Two Pointers (Read & Write)

## Recognition
- Compress characters in-place.
- Consecutive duplicate characters.
- Return the new length.
- O(1) extra space required.

## Core Idea
Use two pointers:

- **Read pointer** scans each group of identical characters.
- **Write pointer** overwrites the array with:
  - the character
  - its count (only if count > 1)

Example:

```text
a a a b b c

↓

a 3 b 2 c
```

## Algorithm
1. Initialize `read = 0`, `write = 0`.
2. While `read < n`:
   - Store current character.
   - Count its occurrences.
   - Write the character.
   - If count > 1:
     - Convert count to string.
     - Write each digit separately.
3. Return `write`.

## Pseudocode

```java
read = 0
write = 0

while(read < n):

    current = chars[read]
    count = 0

    while(read < n && chars[read] == current):
        read++
        count++

    chars[write++] = current

    if(count > 1):

        for(digit : String.valueOf(count)):
            chars[write++] = digit

return write
```

## Key Syntax

```java
chars[write++] = current;

String cnt = String.valueOf(count);

for(char ch : cnt.toCharArray())
    chars[write++] = ch;

return write;
```

## Complexity

Time: O(n)

Space: O(1)

## Template Insight

Whenever:
- Modify array/string in-place.
- Read input and write transformed output.
- Consecutive groups are processed.

Think:
**Read Pointer + Write Pointer**

## Similar Problems

- Remove Duplicates from Sorted Array
- Move Zeroes
- Remove Element
- Compress String (Run-Length Encoding)

## Revision (15 sec)

- Read one group at a time.
- Count frequency.
- Write character.
- Write count only if > 1.
- Return write pointer.
- O(n), O(1).
