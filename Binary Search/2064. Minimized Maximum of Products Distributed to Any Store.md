# 2064. Minimized Maximum of Products Distributed to Any Store

## Pattern
Binary Search on Answer

## Recognition
- Minimize the **maximum** value.
- Search space is a range of possible answers.
- Need to check if a candidate answer is feasible.
- Keywords:
  - "Minimum possible maximum"
  - "Maximize the minimum"
  - "Smallest value satisfying a condition"

## Core Idea
Instead of binary searching an index, binary search the **answer**.

Let `mid` be the maximum number of products allowed in any store.

For each product quantity:

```text
storesNeeded = ceil(quantity / mid)
```

If the total stores required is ≤ `n`, then `mid` is feasible.
Try a smaller answer.

Otherwise, increase `mid`.

## Algorithm
1. Search space:
   - `low = 1`
   - `high = maximum quantity`
2. While `low <= high`:
   - Compute `mid`.
   - Calculate stores required.
   - If stores ≤ `n`:
     - Store answer.
     - Search left.
   - Else:
     - Search right.
3. Return answer.

## Pseudocode

```java
low = 1
high = maximum element
answer = high

while(low <= high):

    mid = low + (high - low) / 2

    stores = 0

    for(quantity : quantities):

        stores += ceil(quantity / mid)

    if(stores <= n):

        answer = mid
        high = mid - 1

    else:

        low = mid + 1

return answer
```

## Key Syntax

```java
int high = 0;

for(int q : quantities)
    high = Math.max(high, q);

int mid = low + (high - low) / 2;

// Integer ceil division
stores += (q + mid - 1) / mid;

answer = mid;
```

## Complexity

Let:
- `m` = number of product types
- `M` = maximum quantity

Time: O(m × log M)

Space: O(1)

## Template Insight

Whenever:
- Need to minimize the maximum.
- Need the smallest feasible value.
- Feasibility can be checked in O(n).

Think:
**Binary Search on Answer**

General Template:

```java
low = minimum possible answer
high = maximum possible answer

while(low <= high){

    mid = low + (high - low) / 2;

    if(isPossible(mid)){
        answer = mid;
        high = mid - 1;
    }else{
        low = mid + 1;
    }
}
```
