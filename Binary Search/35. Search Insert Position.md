# 35. Search Insert Position

## Pattern
Binary Search

## Recognition
- Sorted array.
- Find target or its insertion index.
- O(log n) time expected.

## Core Idea
Perform a standard binary search.

- If target is found, return its index.
- If not found, the `left` pointer will indicate the correct insertion position after the loop ends.

## Algorithm
1. Initialize `left = 0`, `right = n - 1`.
2. While `left <= right`:
   - Compute `mid`.
   - If `nums[mid] == target`, return `mid`.
   - If `nums[mid] < target`, search right half.
   - Else, search left half.
3. Return `left`.

## Pseudocode

```java
left = 0
right = n - 1

while(left <= right):

    mid = left + (right - left) / 2

    if(nums[mid] == target)
        return mid

    else if(nums[mid] < target)
        left = mid + 1

    else
        right = mid - 1

return left
```

## Key Syntax

```java
int left = 0;
int right = nums.length - 1;

int mid = left + (right - left) / 2;

return left;
```

## Complexity

Time: O(log n)

Space: O(1)
