# 34. Find First and Last Position of Element in Sorted Array

## Pattern
Binary Search (Lower Bound + Upper Bound)

## Recognition
- Sorted array.
- Need first and last occurrence of a target.
- O(log n) time expected.
- Duplicates may exist.

## Core Idea
Perform **two binary searches**:

1. Find the **first occurrence (lower bound)**.
2. Find the **last occurrence (upper bound)**.

Instead of stopping when the target is found:
- Continue searching **left** for the first occurrence.
- Continue searching **right** for the last occurrence.

## Algorithm
### First Occurrence
1. Binary search.
2. If target found:
   - Store index.
   - Search left half.
3. Return stored index.

### Last Occurrence
1. Binary search.
2. If target found:
   - Store index.
   - Search right half.
3. Return stored index.

## Pseudocode

```java
// First Occurrence
left = 0
right = n - 1
first = -1

while(left <= right):

    mid = left + (right - left) / 2

    if(nums[mid] == target):
        first = mid
        right = mid - 1

    else if(nums[mid] < target):
        left = mid + 1

    else:
        right = mid - 1


// Last Occurrence
left = 0
right = n - 1
last = -1

while(left <= right):

    mid = left + (right - left) / 2

    if(nums[mid] == target):
        last = mid
        left = mid + 1

    else if(nums[mid] < target):
        left = mid + 1

    else:
        right = mid - 1

return [first, last]
```

## Key Syntax

```java
int ans = -1;

mid = left + (right - left) / 2;

// First occurrence
right = mid - 1;

// Last occurrence
left = mid + 1;

return new int[]{first, last};
```

## Complexity

Time: O(log n)

Space: O(1)

## Template Insight

Whenever:
- Sorted array.
- Need first/last occurrence.
- Duplicates present.

Think:
**Two Binary Searches**

- First occurrence → move left after match.
- Last occurrence → move right after match.

## Revision (15 sec)

- Run binary search twice.
- First occurrence → store answer, move left.
- Last occurrence → store answer, move right.
- Initialize answer as `-1`.
- O(log n), O(1).
